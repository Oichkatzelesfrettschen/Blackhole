# Spline Sans Mono (vendored)

A monospace typeface used for the Temporal Disturbance campaign UI. Vendored
into the repository so the build is self-contained and does not depend on a
system font install.

- Family: Spline Sans Mono
- Version: 1.002
- Authors: Eben Sorkin and Mirko Velimirovic, Sorkin Type
- Copyright: 2022 The Spline Sans Mono Project Authors
- Upstream: https://github.com/SorkinType/SplineSansMono
- Also on Google Fonts: https://fonts.google.com/specimen/Spline+Sans+Mono
- License: SIL Open Font License 1.1 (see OFL.txt in this directory)

The OFL permits bundling and redistribution provided the license text travels
with the font (OFL.txt here) and the Reserved Font Name "Spline Sans Mono" is
not applied to any modified version. The files here are the unmodified upstream
release, copied from the Arch package `ttf-spline-sans-mono 1.002-1`, kept apart
from any system font copy.

Files:
- SplineSansMono-Regular.ttf -- body text
- SplineSansMono-Medium.ttf -- slightly heavier weight for headings
- OFL.txt -- the license, required to accompany the font
