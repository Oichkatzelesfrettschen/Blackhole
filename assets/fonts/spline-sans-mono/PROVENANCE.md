# Spline Sans Mono (built from source)

The monospace typeface used for the Temporal Disturbance campaign UI. The
design source is vendored and the `.ttf` is built from it at compile time by
fontmake -- there is no font binary committed to the repository.

- Family: Spline Sans Mono
- Authors: Eben Sorkin and Mirko Velimirovic, Sorkin Type (see src/AUTHORS.txt)
- Copyright: 2022 The Spline Sans Mono Project Authors
- Upstream: https://github.com/SorkinType/SplineSansMono
- License: SIL Open Font License 1.1 (OFL.txt in this directory)

## What is in the tree

- `src/SplineSansMono.glyphs` -- the Glyphs design source, the single source of
  truth for the font.
- `src/AUTHORS.txt` -- upstream author list.
- `OFL.txt` -- the license. The OFL requires it to accompany the font, and
  requires the reserved name "Spline Sans Mono" to stay with the unmodified
  design; the source here is upstream-unmodified.
- `SplineSansMono-Regular.ttf` -- NOT committed. Generated by the build (see
  below) and git-ignored.

## Build

The CMake desktop build compiles the Regular instance from the source with
fontmake (found via `FONTMAKE_EXECUTABLE`, overridable), equivalent to:

    fontmake -g src/SplineSansMono.glyphs -i "Spline Sans Mono Regular" \
             -o ttf --output-dir .

fontmake is a Python tool; install it with `pip install fontmake` (a virtualenv
is fine -- pass its `fontmake` via `-DFONTMAKE_EXECUTABLE=/path/to/fontmake`).
The desktop targets depend on the generated `.ttf`, so it is rebuilt whenever
the `.glyphs` source changes. Tests and the headless campaign_sim do not use
the font and do not require fontmake.
